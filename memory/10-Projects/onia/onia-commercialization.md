# Onia 商业化方案（收费、功能拆分与 AI 成本）

写作日期：2026-11-19（亚洲/上海）。  
本文是可执行的收费与功能拆分成稿，对齐已拍板的技术路径（一期模式 A）和 AI 成本约束。价格、草稿额度、单次成本均为**假设**，用于内部对齐与实验，不是已验证的最优价，也不是对外承诺。不编造花费、ROAS、销量、市场规模、转化率；无公开来源处写「未见公开数据」。

**相关文档**：[onia-business-model.md](onia-business-model.md)（竞品与定位）· [onia-official-api-inbound.md](onia-official-api-inbound.md)（官方入站技术路径）· [onia-status-overview.md](onia-status-overview.md)（功能与技术现状）

## 1. 已拍板前提

2026-11-19 用户拍板硬约束改写：

- **永久禁止**：cookie / `sessionid` / 私有 GraphQL · Direct · CDN。服务端不得用私有面打 Instagram。
- **可选允许**：OAuth 的 Graph / Page token，且**只打官方端点**。Graph token 不等于 cookie。
- **一期按模式 A 推进**：官方 Webhook 入站 → Signal → 会话视图 → Agent 草稿 → Policy；**`send_reply` 仍走设备**；默认 `review`。
- **评论转私信**：不做 WebView；走官方 `comments` + Private Replies，作为模式 A 下的**局部官方发送特例**（通常一条评论只能先私回一条，7 天内；对方回复后进入约 24 小时窗口）。
- **模式 B**（服务端官方代发私信）为显式二期开关，**不默认打开，不进入近端售卖包**。须再次拍板后再做产品化。

商业叙事：Onia 是「双通道」产品——专业号可走官方入站与官方评论私信；个人号或未授权账号仍走本机 WebView。不宣传「官方认证 / 不会封号」，也不把非官方脚本获客当卖点。

---

## 2. 怎么卖：一个产品、两块能力

不要做成两个品牌，也不要把本机脚本和官方 API 捆成同一个「更不容易封号的自动获客」。

| 能力包 | 卖什么 | 发送怎么走（一期） | 谁能用 |
|--------|--------|--------------------|--------|
| **私信助手（Inbox）** | 一对一收信、AI 草稿、默认人审、会话接管、数据页 | 入站可云端 Webhook；`send_reply` 仍在设备 | 个人号走本机听；专业号可云端收信 |
| **官方触发（Triggers）** | 评论转私信、公开评论回复、Story 回复/提及、关注检查、窗口与按钮确认 | Private Replies 等官方发送特例 | **仅专业号 / 商业号**；须 App Review 通过后才公开卖 |

二期才放入更高档、且不阻塞一期开售的能力：多步 Flow、线索采集（邮箱/电话）、链接追踪与一次跟进、有限 `auto`、多账号与只读席位。

**明确不卖**：向列表做营销广播或无限群发、用非官方脚本做评论转私信或刷关注、封号保险、WhatsApp（须向 Meta 付消息费）、模式 B 云端代发私信。

## 3. 收费形式

- **主形式**：月付订阅；年付大约少两个月的钱。
- **计量主轴**：绑定的 Instagram 账号数、在线设备数、**Agent 草稿次数**（或 AI 积分）。
- **不加为主计费**：按成功发出的消息条数抽成——会激励多发，和平台风控、窗口规则相冲突。
- **超额**：额外账号、额外设备、草稿加量包。加量包按预估 AI 成本的 **3–5 倍**定价（假设），覆盖高峰价、安全二次调用和余量。
- **模板 vs 模型**：官方触发默认用固定话术 / 关键词规则，**不占或少占**草稿额度；只有「AI 生成的草稿或 AI 生成的评论回复」才扣次。

开售前门槛（产品，不是定价）：真实模型真机自动回复跑稳之前，不把「AI 自动回复已生产稳定」写成付费卖点；官方触发在 Meta App Review 通过前只做专业号内测，不公开收款。

## 4. 功能与档位拆分

| 档位 | 假设价（USD/月） | 私信助手 | 官方触发 | AI 能力与额度（假设） | 不包含 |
|------|------------------|----------|----------|----------------------|--------|
| **Free** | $0；或 14 天更高档试用 | 1 账号、1 设备；仅 `review` / `suggest` | 无 | 基础草稿；短上下文、非思考；假设 50–100 条/月 | `auto`、真实模型完整能力、多账号 |
| **Solo** | $15–19 | 1–2 账号 / 设备；数据页全开；专业号可云端收私信，发送仍在设备 | 无 | 真实模型基础草稿 + AIPolice / 关键词 RAG / 重复缓存；假设 500 条/月 | 评论转私信、Flow、团队席位、无限 AI |
| **Pro** | $35–49 | 3–5 账号 / 设备；可选有限 `auto`（须手动打开 + 审计日志，并计入草稿额度） | **包含**：评论转私信、公开评论回复、Story 触发、关注检查 | 更高草稿额度（假设 1,500–2,500 条/月）；评论模板不扣或少扣；「AI 写评论回复」才扣次 | 广播、代运营、模式 B |
| **Studio** | $79–129 | 更多账号、只读席位、优先支持 | 同 Pro | 更高额度；Flow、线索、链接追踪（二期能力放到此档或 Pro 加购） | 完整 CRM、WhatsApp |

起步建议：先公开 Solo（卖私信助手），Pro 等官方审核通过后再上。不要一上来按评论转私信和 ManyChat 硬拼价。

## 5. AI 成本与能力（必须一起设计）

成本出在「一对一会话里出高质量草稿」，不出在评论关键词匹配。评论触发默认走模板，几乎不烧模型。

### 5.1 公开单价（非我方成本实测）

现网 Agent 适配 DeepSeek。公开单价以 [DeepSeek Models & Pricing](https://api-docs.deepseek.com/quick_start/pricing/) 为准（查阅日 2026-11-19），主推 `deepseek-flash`：

| 项目 | 高峰 | 空闲（高峰一半） |
|------|------|------------------|
| 百万 token 输入（缓存命中） | $0.006 | $0.003 |
| 百万 token 输入（缓存未命中） | $0.30 | $0.15 |
| 百万 token 输出 | $1.20 | $0.60 |

高峰时段以官方文档为准（文档写明 UTC 时段；北京时间对应工作日白天部分时段）。模型与价格会变，套餐额度要按账单复核，不要写死为永久成本。

### 5.2 单次成本假设（未见生产均值）

未见 Onia 生产环境的平均 token 用量。下列为**工作假设**，仅用于档位留白：

- 一条待审草稿若带一段会话上下文（数千到上万 token 输入、数百到约一千输出），在 Flash、高峰、缓存未命中时，单次成本多在**几美分以下**。
- 打开思考模式、塞入过长历史、或安全审核再跑一轮，单次可能翻几倍。
- 因此：**免费必须限额；付费不得承诺无限智能回复**；能模板解决的官方触发不要默认走大模型。

有一周真实 token 账单后，应按「目标毛利」倒推各档草稿额度，替换本节假设数字。

### 5.3 能力分层（和档位绑定）

| 层级 | 能力 | 成本含义 | 放到哪一档 |
|------|------|----------|------------|
| 基础草稿 | 短上下文、非思考、只出待审回复 | 低 | Free / Solo |
| 安全与风格 | AIPolice、关键词 RAG、跨会话重复缓存 | 可能增加一次或数次调用 | Solo 起标配；Free 不做无限量完整安全链 |
| 高质量回复 | 更长记忆、更稳的真实模型、必要时思考模式 | 明显高于基础草稿 | Solo / Pro 的付费点；真机未验证前不写成已稳定卖点 |
| 有限 `auto` | 草稿自动发送 | 最费且风险最高 | 仅 Pro 以上，手动打开，计入草稿额度 |
| 官方触发 | 关键词 + 模板为主；可选「用笔记生成回复」 | 模板近乎零模型成本 | 模板在 Pro；AI 生成的评论回复扣草稿次数 |

默认路由：Flash；缩短提示词、尽量命中缓存；能模板解决不用模型。

## 6. 一期对外可承诺与不可承诺

**可以承诺（在对应能力真正落地之后）**

- 专业号：云端收私信，设备不必一直开着听（发送仍要设备在线，除非未来另拍板模式 B）。
- 默认先审后发；会话可接管停发。
- 专业号：官方规则下的评论转私信（一条评论先私回一条，受窗口限制）。
- 服务端不持 cookie / `sessionid`，不用私有接口代打 Instagram。

**不可以承诺**

- 不封号、官方 Partner 认证、无限 AI、窗口外随意群发。
- 个人号也能用官方 Webhook / 评论转私信。
- 模式 B 已可用。
- 真实模型尚未完成真机验证时，宣称「AI 自动回复已生产稳定」。

## 7. 推进顺序

1. **现在**：不公开收款。把收费页与档位当作实验稿；完成真实模型真机验证。
2. **Solo 开售**：私信助手（本机或云端收信 + 人审草稿 + 设备发送）。支付类目需与 MoR/PSP 书面确认后再接。
3. **Pro 开售**：Meta App Review 与商业验证通过后，打开官方触发。
4. **Studio / Flow / 线索**：二期，有付费用户反馈后再加。
5. **模式 B**：单独决策，不随 Pro 自动开通。

验证方法仍见 [onia-business-model.md](onia-business-model.md) §7，本文不重复编造目标转化率。

## 8. 假设与范围

- 客单价锚定公开创作者工具量级（约 $9–$49/月档），Onia 落在个人工具上沿到轻团队下沿；**不是**竞品报价承诺。
- 加量包 3–5 倍成本、各档草稿条数为假设，待真实账单校准。
- 一期架构与事件边界以 [onia-official-api-inbound.md](onia-official-api-inbound.md) 为准；本文不改实现方案。
- 未改 Onia 仓库；未写飞书；未做投资建议。
