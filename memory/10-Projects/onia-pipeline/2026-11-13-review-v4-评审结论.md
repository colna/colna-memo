## 总判断

**「有条件可合」** — 客户端（client/ + scripts/）可合；服务端带出不完整（db/state/auth/config/error/idempotency 模块缺失），无法机器验收。

## M 级问题（M1–M8）

| # | 问题 | 位置 |
|---|------|------|
| M1 | server/lib.rs 模块树断裂：6 个 `pub mod` 无源码；`http`/`ws` 与文件名 `http_devices.rs`/`ws_mod.rs` 不匹配且无 `#[path]` | server/lib.rs |
| M2 | 缺 `crates/onia-protocol`（仅存 onia-device） | crates/ |

| M8 | 中文错误文案「账号未绑在该设备」 | server |

## S 级建议（S1–S14）

- 幂等分支 `PolicyView::default()` 不一致
- promote/parse 软失败
- 事务 `rows_affected` 未检查
- `cancel_todo unwrap_or(Pending)`
- redispatch 仅 hello 触发
- hello validate 失败无 error envelope
- CORS `mirror_request` + `credentials`
- 重绑 cancel/move 硬失败 vs `cancel_open_todos_for_binding` 软失败
- register_screen 服务器地址字段
- index.html 演示壳
- tsconfig include 未覆盖 test/
- 测试覆盖缺口：sync_profile mismatch / probeSession 失败
- errors.ts `cls`/`error_class` 双别名
- WebView 真机验证

## 已核对无问题

- UA 去 `; wv` / `Version/4.0`
- hello 空 capabilities 防护
- social_proxy.js 空 if
- demo/live 分支
- HostContext 回退链
- `SocialProxy = { execute, probeSession }`
- 幂等键前缀 `device-bind:` / `account-bind:` / `behavior-result:` / `dev-device-account:`
- 信封 `v/kind/id/trace_id/idempotency_key/ts/payload` 仅 `v=1`

- 五项不回退项：Hero `Clip.none`、可注入 Session 延迟、`buttonActive`、注册成功 `popUntil`、密码 ≥8 位
