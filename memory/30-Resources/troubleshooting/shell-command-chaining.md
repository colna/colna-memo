# 命令链编排

**坑（2026-10-13）**：`gh pr view ... && cat >> memo` —— gh 首次 GraphQL 瞬时抖动失败 → `&&` 短路，**memo 没写**（后发现重试 gh 才补记）。

**根因**：远程命令（gh / git fetch / 网络请求）有瞬时失败率；`&&` 链把「本地记录」这种重要副作用搭在上面，一挂全挂。

**修法**：
- 重要的本地副作用（写 memo / 改文件 / 落日志）**先做**，或与可能失败的命令**分开执行**；不要用它兜后。
- 批量里远程查询可能失败 → 用 `;` 分段或不阻塞本地记录。
