# 币安最小下单量与「双腿资本 = 2N」

来源：2026-11-04 量化交易 P0-A 实测（`shared/binance_p0a/REPORT.md` / `REPORT_CONTINUOUS.md`，数据分析师交付）。实测数据时点 `2026-11-04T04:51:46.708Z`。

## 症状

按「两腿各 5 USDT」规划 10 USDT 中性套利，账面看着刚好：minNotional 全是 5.00（DOGE 1.00）。实际一算：**一张双腿单都开不出来**，而且年化收益被高估约 2 倍。

## 三个数（根因）

### 1. `minNotional` ≠ 最小实际支出

数量必须落在 `stepSize` 网格上，且 `qty × price ≥ minNotional`，所以目标 5.00 USDT 会被**向上取整**：

| 标的 | 5.00 理论 qty | 取整后 qty | 实际名义 |
|---|---|---|---|
| BTC | 0.00006475 | 0.00007000 | **5.4054（+8.1%）** |
| XRP | 3.9417 | 4.0000 | 5.0740 |
| TRX | 15.5039 | 15.6000 | 5.0310 |
| DOGE | 67.6041 | 68.0000 | 5.0293 |
| ADA | 26.6525 | 26.7000 | 5.0089 |
| ETH | 0.00219994 | 0.00220000 | 5.0001 |

BTC 因 stepSize 相对价格过大，惩罚 8.1%；小资金项目里 8% 就是「开得出 / 开不出」的分界。

### 2. 资本 = `2N`，不是 `N`

Delta 中性要求双腿名义相等：现货 1x 全额 + 永续 1x 保证金 = **2N**。

- 按单腿 notional 算的年化，必须 ×0.5 才是**资本收益率**。
- 本例产品口径用 notional 8.33 / 资本 10，实际双腿要 16.66 → 年化被高估 **1.7×**。
- BTC 最小可行双腿资本 = 5.4054 × 2 = **10.8189**，ETH = 10.0078。10 USDT 连最低标的都差 0.0078。

### 3. 资金费「最大值」不是「均值」

12 个月 1095 次/标的实测里，5 个标的单次最大费率都恰好是 **0.0100%/8h**、日聚合最大 **0.0300%**——用 0.01% 建模等于拿**最好的一天**当均值，真实均值只有约 1/3（BTC 0.0032%/8h，日均 0.0095%，年化 3.47%）。乐观假设下覆盖 VPS 仍需 notional 548（真实均值 1,728）。

## 修法 / 验证

1. 拉 `exchangeInfo` 后，用 `ceil(target/price/stepSize)*stepSize*price` 算**实际**最小支出，别只看 `minNotional`；同时记下取价时点。
2. 一切收益率标注分母：`/notional` 还是 `/capital`；双腿策略用 `2N`。
3. 资金费统计至少看：均值、中位、负值天数占比、最长连负。只看最大值会把结论带偏 3 倍。
4. 合约侧（`fapi`）规格必须单独实测，现货 `stepSize` 不能外推。

## 边界

- 以上为 2026-11-04 单时点规格；`stepSize` / `minNotional` 交易所可调整，复用前重拉。
- 未计基差、维持保证金、强平、提币费；费率（VIP0 / BNB 抵扣）未核实。
