# 负责项目

## 全栈工程师（前端为主）· 独立负责社交产品四条核心业务线

覆盖 C 端女性陪聊（PWA）、社媒获客自动化（SP）、运营后台（Minerva）、RN 多品牌 App 矩阵；以复杂 C 端交互、多端交付、浏览器端自动化与数据可视化为核心，兼具 Node.js 后端与 Android 容器交付能力。

### 一、PWA · C 端女方陪聊作战端
**业务**：女方核心经营端 —— 聊天 / 音视频通话 / 社媒交换 / 实名探真 / 按分钟计费，直接关系女方留存与平台合规收入。

- **聊天与消息**：主导聊天主链路与多模态消息优化，攻克套壳 WebView 的性能、内存与移动端兼容瓶颈，保障核心聊天体验稳定。
- **音视频通话与计费**：主导 web / native 双通话栈解耦重构，统一两端体验与业务规则（单点维护）；落地按分钟计费与通话违规检测扣款，保障计费合规。
- **实名探真**：搭建自拍 / 语音实名验证流程（录制 → 送审 → 通过 / 失败），实现 UI 与后端审核解耦，方案可复用易扩展。
- **社媒交换（IG / Snapchat）**：交付女方侧授权登录、交换请求受理、社媒名片送达与奖励结算全链路，将社媒交换由 IG 单平台扩展至 IG + Snapchat 双平台。

### 二、SP · Social-Proxy 社媒代理自动化
**业务**：IG / Snapchat 多平台账号自动化运营中台 —— 自动完成加好友、回关、私信、主页同步等获客动作，把人工运营规模化。

- **获客动作自动化**：设计并交付注入式浏览器自动化框架，驱动真实 DOM 完成关注、私信、拉消息、切换专业账号等动作，支持页面跳转后断点续跑；攻克多语言 DOM 适配、防误触发跳步与真机稳定性问题。
- **自动化决策管线**：设计 Signal（事实）→ Todo（决策）→ Behavior（执行）三层管线，打通「交换 → 回关 → 静音 → 开场私信」获客动作链与私信自动回复管道。
- **多平台接入与设备矩阵**：主导 Instagram 和 Snapchat 接入；建设设备连接管理与实时在线能力（NestJS + WebSocket + Redis）；Android 容器支持单账号多平台多开挂机。

### 三、Minerva · 运营后台
**业务**：SP 与陪聊业务的内部运营 admin —— 设备管理、脚本监控、实时 / 历史数据看板，支撑运营决策。

- **构建与交付链路**：修复 turbo 缓存失效与 minerva-server 双重构建；以 `pnpm deploy` 精简镜像替代整库 node_modules —— 镜像导出 110s→13s（约 8×）、依赖拷贝 52s→1.4s（约 37×）、单次构建整体提速约 40%。
- **类型安全治理**：移除构建期 `tsc || true` 静默兜底并消除生成物类型歧义 —— 类型错误在 CI 全量暴露并清零，杜绝带病上线。
- **前端架构收敛**：下线策略引擎旧页及配套 API（净删约 3400 行）；Actions 页 V2→V3 重构并合并进统一「Action 控制台」，API wrapper 与信号类型枚举收敛为单一实现。
- **数据统计层重构**：重做在线统计口径 —— 多设备并发时长区间并集去重（gaps-and-islands）、明细查询防扇出、分时段改日均口径、导出截断显式化；根修线上「当前在线恒 0」。
- **BFF 流式架构**：minerva-server 作为 BFF 流式透传 social-proxy（不缓冲），配合前端流式写盘，保障大体量 CSV 导出全程内存恒定；数据边界归位。

### 四、RN · 多品牌 App 矩阵（React Native 多包 Monorepo）
**业务**：以一套社交产品引擎支撑多款独立品牌 App 并行研发与商店上架（Luka、Sofia、Koda、Beth 等）—— 共享匹配 / 聊天 / 通话 / 支付等业务能力，各品牌独立视觉、商店身份与运营配置。

**工程**：Expo / React Native 多应用 monorepo（pnpm workspace 多包共享、源码消费）；`business-*` 领域引擎 + `rn-*` 基础设施包；依赖边界强制校验；模板派生 + 迁移机制起新 App。

- **多品牌 App 交付**：主导 Luka 从模板派生到上架准备的全流程（全 App 视觉 / 体验重做、性能优化、安全加固）；负责 Sofia 货币体系与桌面小组件、Koda 全量缺陷修复与恋爱铃 · 假来电增长系统接入、Beth 上架矩阵与品牌配置。
- **共享能力建设**：主导桌面小组件包从 0 到 1 并接入多 App；自建通话充值原生模块（iOS / Android 双端）；迭代支付与货币化共享包。
- **工程规范**：参与共享包边界规则与模板迁移机制落地，统一跨 App 架构约束，主导跨 App 根因修复。
