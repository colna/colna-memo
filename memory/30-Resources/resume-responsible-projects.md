## 全栈工程师（前端为主）· 独立负责社交产品四条核心业务线

覆盖 C 端女性陪聊（PWA）、社媒获客自动化（SP）、运营后台（Minerva）、RN 多品牌 App 矩阵；以复杂 C 端交互、多端交付、浏览器端自动化与数据可视化为核心，兼具 Node.js 后端与 Android 容器交付能力。

### 一、PWA · C 端女方陪聊作战端
- **业务**：女方核心经营端 —— 聊天 / 音视频通话 / 实名探真 / 按分钟计费，直接决定女方留存与平台合规收入。
- **形态**：React + TypeScript 移动端 PWA，运行于 Android 套壳 WebView 容器。
- **业务模块**：
  - **聊天与消息**：聊天主链路与多模态消息；主导套壳 WebView 下的性能、内存与移动端兼容优化。
  - **音视频通话与计费**：主导通话模块 web / native 双端解耦重构 —— 两端体验与业务规则统一、规则单点维护；实现按分钟计费与通话合规检测扣款结算。
  - **实名探真**：搭建自拍 / 语音实名验证流程（录制 → 送审 → 通过 / 失败），UI 与后端审核解耦、可复用易扩展。
- **业务价值 · 量化**：【填:探真通过率 / 通话计费准确率 / 女方端崩溃率↓% / 通话相关 bug 数↓】

### 二、SP · Social-Proxy 社媒代理自动化
- **业务**：IG / Snapchat 多平台账号自动化运营中台 —— 自动完成加好友、回关、私信、主页同步等获客动作，把人工运营规模化。
- **业务模块**：
  - **获客动作自动化（浏览器端核心）**：设计并交付注入式浏览器自动化框架，驱动真实 DOM 完成关注、私信、拉消息、切换专业账号等动作，支持页面跳转后断点续跑；攻克多语言 DOM 适配、防误触发跳步与真机稳定性问题。
  - **自动化决策管线（后端）**：设计三层管线 Signal（事实）→ Todo（决策）→ Behavior（执行）；打通「交换 → 回关 → 静音 → 开场私信」获客动作链与私信自动回复管道。
  - **多平台与设备矩阵**：主导 Snapchat 接入方案；设备连接管理与实时在线（NestJS + WebSocket + Redis）；Android 容器支持单账号多平台多开挂机。
- **业务价值 · 量化**：【填:覆盖账号数 / 日均动作量 / 人工替代率 / 获客转化↑%】

### 三、Minerva · 运营后台
- **业务**：SP 与陪聊业务的内部运营 admin —— 设备管理、脚本监控、实时 / 历史数据看板，支撑运营决策。
- **业务模块**：
  - **设备与脚本运营（前端）**：SP 设备管理、脚本错误日志流式导出。
  - **实时 / 历史看板（前端 + 后端）**：基于 Umi / React + echarts 构建实时在线统计与历史曲线；后端 Fastify 分层（当前在线读 Redis、历史曲线基于 Postgres 去重合并在线区间）；定位并修复线上「当前在线恒 0」问题（绕开基础设施限制，产品级换源）。
- **业务价值 · 量化**：【填:看板服务运营人数 / 数据延迟 X→Y / 问题定位效率↑】

### 四、RN · 多品牌 App 矩阵（React Native 多包 Monorepo）
- **业务**：以一套社交产品引擎支撑多款独立品牌 App 并行研发与商店上架（Luka、Sofia、Koda、Beth 等）—— 共享匹配 / 聊天 / 通话 / 支付等业务能力，各品牌独立视觉、商店身份与运营配置。
- **工程**：Expo / React Native 多应用 monorepo（pnpm workspace 多包共享、源码消费）；`business-*` 领域引擎 + `rn-*` 基础设施包；依赖边界强制校验；模板派生 + 迁移机制起新 App。
- **业务模块**：
  - **多品牌 App 交付**：Luka（从模板派生到全 App 视觉 / 体验重做、性能优化、安全加固与上架准备的全流程）；Sofia（货币体系与桌面小组件）；Koda（全量缺陷修复、恋爱铃 · 假来电增长系统接入）；Beth（上架矩阵与品牌配置）。
  - **共享能力沉淀**：桌面小组件包（从 0 到 1 并多 App 接入）；通话充值原生模块（iOS / Android 双端）；支付与货币化共享包迭代。
  - **工程规范**：参与共享包边界规则与模板迁移机制落地，跨 App 根因修复与一致性保障。
- **业务价值 · 量化**：【填:交付 / 上架 App 数 / 性能提升指标 / 商店审核情况】
