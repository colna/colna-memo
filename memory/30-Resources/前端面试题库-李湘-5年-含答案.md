# 前端面试题库（李湘 · 5年 · 杭州 15-20K · 含参考答案）

> 依据简历定制：5 年（拼多多 3 年 → 上海仙软 2 年），主线是电商高并发 + 全栈 RAG 知识库 + GIS 物流 + 跨端音视频/小程序。
> 建议 70-85 分钟：业务 15 / 技术 50 / 反问 5-10；**必问** 标在题前。简历原文：`~/Downloads/【前端开发工程师_杭州+15-20K】李湘+5年.pdf`。
> 出题原则：她的差异点是「全栈 + AI」，但简历顶部「未在职」与工作经历「2024/07-至今」矛盾，且 5 年做到「全栈项目负责人」需要验证含金量。RAG 与 GIS 是主深挖区，拼多多项目要区分「项目光环」与「个人边界」。

## 一、业务与动机（15 分钟）

1. **必问** 简历顶部写「未在职，目前正在找工作」，工作经历却写「2024/07 - 至今 上海仙软」。哪个是准确的？如果已离职，最后工作日、离职原因是什么？这段空窗在做什么？
   - 期待：坦诚说明（简历未更新 / 刚离职 / 项目结束），时间线自洽，能提供离职证明或社保记录。
   - 警惕：支支吾吾、前后矛盾；把在职写成离职或反之；空窗说不清。
2. 拼多多 3 年 → 上海仙软 2 年：为什么从大厂去乙方/外包？「全栈项目负责人」带几人、向谁汇报、客户是谁、项目金额量级？你日常写代码占比多少？
   - 期待：真实动机（全栈 / 管理 / 回杭州 / 薪资 / 项目机会）；职责边界清晰；不贬低前司。
   - 警惕：把「参与」说成「负责人」；团队人数、客户、交付物说不清。
3. 上海仙软是外包吗？甲方需求频繁变更时，你怎么控制范围、排期与质量？举一次延期或返工。
   - 期待：需求边界、变更记录、验收标准、风险升级；不把加班当唯一解法。
4. 求职意向写「全栈开发、AI 应用开发」，为什么投前端？如果入职后只做前端，你能接受吗？长期想走全栈还是前端专家？
   - 期待：动机真实、岗位匹配；能说清前端基本盘 + 全栈加分；不把前端当跳板。
   - 警惕：明确只想做 AI/后端；对前端无热情。
5. 5 年经验，你如何定义自己的职级？对标 15-20K，你的差异化是什么？
   - 期待：客观自评 + 证据（高并发电商 / RAG 全栈 / GIS / 跨端）；不虚高。
6. **必问** 拼多多「百亿补贴秒杀」：你具体负责哪部分？核心链路还是辅助模块？高并发下前端真正的挑战是什么？你做了什么？
   - 期待：诚实区分「我做的」与「团队做的」；高并发前端挑战（CDN/静态资源、接口降级、库存与倒计时、重复提交、限流、白屏、监控）。
   - 警惕：把项目光环当个人成绩；简历写「基础交互/静态页面」却宣称主导高并发架构。
7. 多多买菜 B 端：虚拟列表、表单联动、异常兜底你做到什么程度？数据量多大？收益怎么衡量？
   - 期待：量级、实现方式、前后对比；能讲清「为什么卡」而不只是「用了虚拟列表」。
8. 送时鲜、宠帮帮、音动 Match 三个项目是并行还是先后？你作为「负责人」有哪些决策权？团队怎么协作？
   - 期待：真实排期与角色；能说清技术选型、评审、Code Review、上线责任。
9. 未来 1-2 年想补什么？如果岗位需要你做性能/工程化而不是 AI，你怎么调整？
10. 反问：团队规模、技术栈、AI 投入、工作地点/加班、到岗时间。

## 二、SKC 知识库与 RAG（15 分钟，重点验证全栈成色）

11. **必问** SKC 整体架构：前端、BFF、Java 服务、向量库、Lucene、大模型 API 怎么分工？你负责哪些模块、大概多少代码？团队几人？
    - 期待：分层清晰；前端（检索/图谱/问答 UI、SSE）、后端（解析/分块/向量化/召回/重排）、模型 API；能说清自己的边界与代码量。
    - 警惕：把「参与架构评审」说成「主导架构」；前后端都「深度负责」但任何一端都讲不细。
12. **必问** 文档入库链路：解析 → 分块 → 向量化 → 索引。分块策略？chunk size / overlap 怎么定？PDF、表格、扫描件怎么处理？
    - 期待：按标题/段落/语义分块、overlap、元数据（来源/页码/权限）、表格结构化、OCR；不同文档类型不同策略。
13. **必问** 混合检索：稠密向量 + Lucene 稀疏检索怎么融合？RRF 公式？为什么用 RRF 而不是加权分数？Cross-Encoder 重排放在哪一步？
    - 期待：双路召回 → 去重 → RRF（Σ 1/(k+rank)，k 常取 60）→ 重排 → topN；RRF 对分数尺度不敏感；Cross-Encoder 精度高但慢，只对候选集重排；能说清 k 值与候选数。
    - 警惕：只会背名词；说不清召回与重排顺序；把 RRF 说成「加权求和」。
14. 向量库选型？embedding 模型怎么选？维度、成本、中文效果？索引类型（HNSW/IVF）与召回参数？
15. Lucene 全文检索：分词器、倒排、召回与重排；和向量结果怎么去重？专有名词/数字场景怎么补？
16. **必问** RAG 幻觉与「无答案」：Prompt 约束怎么设计？引用溯源怎么做？如何判断知识库没有答案而不是硬编？
    - 期待：system 约束（只依据上下文/允许拒答）、引用片段 ID、阈值/重排分数/LLM 自检、无答案兜底；前端展示引用与置信度。
    - 加分：引用可点击回到原文片段，而不只是显示文件名。
17. 评测：怎么衡量召回率、答案质量、引用准确率？有标注集吗？离线评测与线上反馈怎么闭环？
    - 期待：召回@k、MRR、答案正确性、引用准确率、人工标注、bad case 归因、回归集；不能只看「感觉」。
18. 高并发与向量计算阻塞：SSE 流式返回怎么设计？Axios「异步非阻塞」具体指什么？防抖解决什么问题、不能解决什么？
    - 期待：SSE 事件协议、首 token、取消、超时、断线重连；后端线程池/异步，前端并发控制；防抖只防重复触发，不防服务端排队。
    - 警惕：把「防抖」当高并发方案。
19. SSE 细节：`EventSource` vs `fetch` 流？POST 怎么流？Nginx 缓冲/超时？断线重连与重复消息？
    - 期待：fetch + ReadableStream、AbortController、`Last-Event-ID`/seq、心跳、`X-Accel-Buffering: no`、代理超时；消息去重。
20. 知识图谱可视化：数据规模？用什么渲染？节点/边过多怎么处理？布局算法在前端还是后端？
    - 期待：Canvas/WebGL（G6/ECharts/cytoscape）、聚类/按需展开、视口裁剪、LOD、后端预计算布局；交互与性能取舍。
21. RAG 安全与权限：企业私有文档，权限怎么落到检索层？prompt 注入、越权召回、数据外发怎么防？
    - 期待：文档级 ACL（检索前/后过滤）、用户身份透传、模型不出域、输入输出过滤、审计；前端不能兜底权限。
22. 你说熟悉 LangChain 和 Harness：分别解决什么问题？Agent 循环、上下文压缩、沙箱执行、自我验证怎么落地？举一个你真正写过的部分。
    - 期待：LangChain（链/工具/记忆/检索编排）vs Harness（长任务运行时：文件持久化、沙箱、上下文管理、验证闭环）；能给出代码级细节与失败案例。
    - 警惕：只罗列名词；把「看过文档」说成「掌握核心机制」。
23. 如果让你从 0 设计企业知识库前端：页面/状态/接口怎么分层？上传、解析进度、检索、流式回答、引用、无答案、重试，状态机怎么画？
24. 大模型成本与延迟：token 预算谁控？如何做多模型切换/降级？首 token 慢从哪查？

## 三、GIS 与物流 TMS（10 分钟）

25. **必问** 品达 TMS：高德地图分层架构怎么设计？BaseLayer / VehicleLayer / TrajectoryLayer 的职责与生命周期？为什么用 `useRef` 管理实例？
    - 期待：实例与 React 渲染解耦、分层职责、卸载销毁、事件解绑；避免重复初始化。
26. **必问** 多车实时渲染卡顿：MassMarks 为什么比 Marker 快？Map + Diff 怎么去重更新？数据频率多高、多少辆车、帧率多少？
    - 期待：MassMarks 走 Canvas/WebGL 批量绘制、减少 DOM；按 vehicleId 做增删改；量级与帧率；节流/批量。
27. 轨迹平滑：Douglas-Peucker 与 Bezier 插值分别解决什么？抽稀会不会丢关键点？跳点/漂移怎么用 Turf + Sliding Window Filter 处理？
    - 期待：DP 减点保形、Bezier 视觉平滑；按距离阈值/时间戳；滑动窗口均值/中值降噪；Web Worker 避免阻塞主线程；坐标纠偏。
28. 轨迹回放控制器：进度拖拽、倍速、暂停怎么实现？时间戳索引怎么驱动点位？实时流与回放怎么切换？
    - 期待：时间轴映射、插值、`requestAnimationFrame`、倍速、暂停恢复；实时/回放状态机。
29. 坐标系：高德用 GCJ-02，GPS 是 WGS84，后端/第三方轨迹怎么统一？换图商怎么办？
    - 期待：边界统一转换、纠偏算法/服务、存原始坐标 + 展示转换；避免来回转换累积误差。
30. 内存泄漏：反复进出页面怎么排查？高德实例、事件、定时器、Worker 怎么销毁？
    - 期待：DevTools Memory 快照、监听数量、detached DOM、WebGL 上下文；cleanup 清单。
31. 虚拟列表：TMS/多多买菜的大表格怎么实现？不定高怎么办？与地图联动时怎么避免全表重渲？
    - 期待：可视区索引、占位、测量缓存、key 稳定、分页缓存；memo/局部订阅。

## 四、React、Vue 与基础（8 分钟）

32. React 渲染机制：render/commit、Fiber 解决什么、Hooks 链表、自动批处理；为什么 `setState` 后不能立即拿到新值？
33. `useEffect` 与 `useLayoutEffect` 区别？依赖数组的坑？闭包陈旧值怎么解？
34. Redux Toolkit 与 Pinia 的差异？宠帮帮为什么选 Redux Toolkit？双身份切换怎么保证状态隔离？
    - 期待：RTK slice/immutable、Pinia 组合式/去 mutation；resetAction、store 重建、持久化清理。
35. RBAC：路由级/页面级/按钮级权限怎么实现？动态路由的坑（刷新丢失、404、权限变更）？前端权限能防住什么、防不住什么？
    - 期待：权限码 + 路由表过滤 + 守卫 + 指令/Hook；刷新重新拉取；后端必须校验；前端只做体验。
36. Vue3 响应式：Proxy vs `Object.defineProperty`；ref/reactive 的坑；Pinia 与 Vuex 差异；大型 Vue 应用怎么组织？
37. TypeScript：联合类型约束权限码、泛型封装请求、类型收窄；`any` 滥用怎么治理？
38. 浏览器/HTTP：强缓存与协商缓存、CORS、Cookie SameSite、JWT 存哪、XSS/CSRF 防护。

## 五、跨端、音视频与小程序（8 分钟）

40. WebSocket 信令：匹配、房间、麦位变更怎么设计消息协议？断线重连后怎么恢复房间状态？消息乱序/重复怎么办？

41. 匹配请求：防抖 + 队列怎么实现？如何避免竞态与重复进房？取消匹配怎么处理？
42. 弱网/离线：音频断连、房间状态不同步怎么兜底？本地缓存与资源预加载策略？
43. 宠帮帮 RBAC 双身份：切换时为什么要 resetAction？动态 Tab/路由重定向怎么做？WS 权限广播后如何刷新？

## 七、评分与红线

**业务面**

- 通过：在职状态与时间线自洽；全栈负责人有真实团队/客户/交付物；拼多多项目能诚实区分个人边界；求职动机与前端岗位匹配。
- 不通过：在职状态前后矛盾；把「参与」包装成「主导」；项目数据全靠猜；明确只想做 AI/后端。

**技术面**

- 15-18K：React/Vue 至少一个讲到原理；RAG 能讲清「检索→重排→生成→引用」主链路；GIS 能讲清分层与一个性能优化；跨端/音视频能讲清权限与重连。
- 18-20K：在上述基础上，能设计状态机/协议；RAG 能讲到 RRF/重排/评测/权限；GIS 能给出量级与算法取舍；有工程化或全栈可复用产出。
- 加分：RAG 的引用溯源与无答案兜底有真实实现；GIS 的轨迹降噪有数据验证；能坦诚讲 AI/全栈项目的失败与返工。

**红线**

- 名词堆砌：Harness、RRF、Cross-Encoder、LangChain 说不清原理与位置。
- 简历包装：把团队成果写成个人；「全栈负责人」讲不出团队与代码。
- 在职状态造假或时间线矛盾。
- 只会页面开发，却宣称主导高并发/全栈架构。
- 安全无意识：RAG 越权召回、prompt 注入、前端权限当后端权限。
