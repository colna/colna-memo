# 前端面试题库（方哲伟 · 2年 · 上海 18-25K · 含参考答案）

> 依据简历定制：东南大学网安硕士（2021–2024）→ 字节 TikTok 国际电商-联盟大前端（2024.07–2026.09）。
> 主线是 Lynx/React 电商前端 + 首屏性能 + 包体积 + Rush 大仓 + 配置化 + AI 研发提效/告警。
> 岗位基准：上海 18–25K 前端。2 年经验挂 3 个「前端负责人」，必须重点验证归属与深度。
> 建议 75–85 分钟：动机 6 / 橱窗性能 14 / 包体积与大仓 12 / 标签配置化 8 / AI 12 / 基础 15 / 手写 10 / 反问 5。
> 出题原则：卖点是「性能数字 + 大仓迁移 + AI 落地」；风险是项目重叠、负责人含金量、指标口径、Lynx 深度、2026.06 后空档。

**卖点**

- 性能优化有完整闭环：埋点拆解 → 分段定位 → 缓存/预请求/直出/预渲染 → P90 数字。
- 工程化：Rush 大仓渐进迁移、双仓同步、多地区构建、CI/CD 卡点、SOP。
- 业务抽象：商品标签服务端配置化，前端工作量 3pd → 0。
- AI 落地不只写 demo：研发全流程 + 告警排查 Agent + 多平台适配 CLI。
- 有跨端框架 Lynx 的一线经验，不是纯 H5。

**风险**

- **归属**：2 年 3 个「负责人」，需区分「接口人/执行负责人」与「技术决策人」。
- **重叠**：PIA 与橱窗重叠、标签与橱窗衔接、AI 两个系统仅 3 个月，时间线要问清投入比例。
- **口径**：FMP 降幅、99.06%、87.9%、24.66pd 都缺定义与样本，必须追到怎么算。
- **Lynx 深度**：可能只会业务 API，不懂双线程/渲染/通信；需单独验证。
- **空档**：2024.07–2025.10 无项目、2026.06–2026.09 无经历。
- **薪资**：2 年、字节背景，上海 18–25K 属正常区间，但要确认离职原因与稳定性。

**现场必须验证的三件事**

1. 挑一个性能数字，追问到「基线、样本、归因、负向指标」四件套。
2. 让他在白板上画 Lynx 一次首屏的完整链路（容器 → JS → 数据 → 渲染）。
3. 现场手写 1–2 题（防抖/并发池/深拷贝），验证基本功不是 PPT 工程化。

## 一、基本情况与动机（6 分钟）

### 1. **必问** 时间线

> 2024.07 入职字节，但简历上第一个项目是 2025.10，中间 15 个月在做什么？2026.06 之后到 9 月离职又在做什么？

- 期待：有具体业务/团队/基建工作；空档有明确安排；时间线自洽。
- 警惕：含糊其辞；把培训/打杂包装成项目；与背调冲突。

### 2. **必问** 为什么离开字节

> 2026.09 离职，是主动还是被动？团队/业务发生了什么？下一份最看重什么？

- 期待：原因具体（业务调整、方向、城市、成长），能说清自己下一步要补什么。
- 警惕：全部归因外部；对离职原因前后不一致。

### 3. **必问** 「前端负责人」的边界

> 三个项目都写负责人。团队几个人？你拍过哪些决策？哪些是 leader/后端/产品定的？

- 期待：能明确区分「我定的」「我执行的」「团队定的」；有具体决策例子。
- 警惕：把所有团队产出说成个人；问三层仍说不清边界。

### 4. 上海与薪资

> 为什么选上海？18–25K 你的预期是多少？如果主要写业务、偶尔做 AI，能接受吗？

- 期待：预期真实；接受前端为主；到岗时间明确。
- 警惕：明显屈就；只想做 AI；对业务开发排斥。

### 5. 最近一年写得最多的代码

> 哪一类代码写得最多？哪一类你明显比同级别快？举一个最近的例子。

- 期待：具体到组件/性能/工程化；能说出「快在哪」。
- 警惕：只报技术名词，说不出产出。

## 二、达人橱窗性能优化（14 分钟）⭐ 核心模块

### 6. **必问** FMP 口径与基线

> 你说的 FMP P90 是怎么定义的？从哪个时间点算到哪个时间点？样本量多大？分地区/设备后每格多少样本？

- 期待：能说清 FMP 的起止点（容器启动/路由/首屏内容可见）、P90 的统计窗口、样本来源、分桶逻辑。
- 追问：「为什么用 P90 不用均值？」「低端机样本够吗？」「埋点丢失/慢上报怎么处理？」
- 警惕：只会背「FMP 首屏」，说不清起止；拿不出样本量。

### 7. **必问** 归因：四个优化一起上，怎么知道谁起作用

> 接口缓存、预请求、首屏直出、预渲染是同时上的吗？各自贡献怎么拆？有没有 AB 或灰度？

- 期待：分阶段灰度、按地区/设备分层、对照组、时间窗口对齐；能说出「哪个先上、哪个收益最大」。
- 追问：「如果大盘同时有版本发布/服务端变更，怎么排除干扰？」「有没有负向指标（内存、崩溃、请求量）？」
- 警惕：把大盘下降全归功于自己；没有对照，只说「上线后就降了」。

### 8. **必问** Lynx 首屏直出/预渲染怎么做

> 在 Lynx 里，「首屏直出」具体直出的是什么？数据从哪来？容器初始化、JS 加载、数据请求、渲染分别省了哪一段？

- 期待：能画出「容器 → 模板/JS → 数据注入 → 首屏渲染」链路；说清直出是 SSR/数据注入/骨架屏中的哪种；缓存失效与降级。
- 追问：「预渲染什么时候触发？缓存多久？内存/包体积代价？」「数据过期了用户看到什么？」
- 警惕：把 H5 的 SSR 概念直接套到 Lynx；说不清直出与缓存的分工。

### 9. 接口缓存与预请求

> 缓存 key 怎么设计？带用户态/实验参数的接口能缓存吗？预请求在什么时机发？失败/重复请求怎么处理？

- 期待：key 含场景/地区/实验/用户维度；区分可缓存与不可缓存；预请求去重、超时、降级；stale-while-revalidate 意识。
- 追问：「预请求打多了会不会把后端打挂？」「登录态变化怎么失效？」

### 10. 低端安卓为什么慢

> 东南亚中低端安卓，慢主要慢在哪？容器、JS 引擎、渲染、内存、图片，你会先查哪个？用什么工具？

- 期待：分阶段埋点 + 真机/弱网；关注 JS 引擎性能、GC、图片解码、布局层级、主线程阻塞。
- 追问：「同样代码 iOS 为什么好很多？」「你怎么在本地复现低端机？」

### 11. 指标反例

> 东南亚 iOS 只降了 22.69%，明显低于其他格。为什么？是优化不适用，还是基线本来就低？

- 期待：能承认边际收益递减/基线差异；分析设备、网络、缓存命中、样本结构。
- 警惕：把所有差异都解释成「iOS 本身快」。

### 12. 如果再做一次

> 这四个优化里，哪个是长期机制、哪个是一次性收益？如果只能保留一个，你留哪个？为什么？

- 期待：区分「机制建设」与「单点优化」；能说出监控/防劣化比一次性数字更重要。
- 追问：「现在这套监控还在跑吗？谁维护？」

## 三、包体积防劣化与 PIA 大仓迁移（12 分钟）

### 13. **必问** 包体积防劣化

> 基线怎么定？预算按页面还是按包？流水线卡在哪个节点？超了是阻断还是告警？误报怎么处理？

- 期待：基线来源、增量对比、阈值、阻断/告警策略、白名单、回滚；能说清「防劣化」防的是什么。
- 追问：「新增一个三方库导致超标，谁来决策？」「source map/图片算不算？」

### 14. **必问** Shadow / Perfsee 选型

> 为什么选这两个？各自解决什么问题？有没有评估过自研或其他方案？

- 期待：能说出对比维度（接入成本、数据口径、CI 集成、维护方）；知道自己方案的边界。
- 警惕：只会说「公司统一用」；说不出平台具体能力。

### 15. **必问** Rush 大仓迁移

> 为什么要迁大仓？渐进式迁移分几步？最小迁移范围怎么确定？第一刀切了什么？

- 期待：动机（统一基建/包体积/跨团队维护）→ 依赖分析 → 最小范围 → 双仓并行 → 切换 → 下线；有回滚方案。
- 追问：「为什么用 Rush 不用 pnpm workspace？」「迁移期间两边代码怎么同步？」

### 16. 依赖治理

> 包名冲突、循环依赖、幽灵依赖，分别怎么发现、怎么修？举一个你实际处理的。

- 期待：`rush check`/依赖图/构建报错；提升公共依赖版本、拆包、显式声明；知道幽灵依赖的成因。
- 追问：「循环依赖为什么会导致构建/运行问题？」「怎么防回归？」

### 17. 双仓同步与重定向

> 新旧仓库同时开发，代码怎么同步？冲突怎么处理？客户端重定向什么时候下线？

- 期待：同步脚本 + 冲突策略 + 灰度切流 + 监控 + 下线条件；知道双写双活的成本。
- 追问：「同步脚本本身出错怎么办？」「怎么保证两边行为一致？」

### 18. 多地区构建

> ROW/EU/US 的构建差异在哪？环境变量、资源路径、时区、灰度怎么隔离？怎么防串环境？

- 期待：构建参数化、环境隔离、产物校验、发布卡点；能说出一次真实的串环境/404 排查。
- 追问：「资源 404 你怎么定位是路径、CDN 还是权限？」

### 19. 大仓的代价

> 上大仓之后，最明显的 new cost 是什么？什么团队/阶段不适合上 monorepo？

- 期待：CI 时长、权限、版本发布、工具链复杂度；能说「小团队/独立发布不适合」。
- 警惕：只讲收益不讲成本。

## 四、商品标签统一配置化（8 分钟）

### 20. **必问** 端到端链路

> 从后端配置到前端展示，完整链路是什么？schema 包含哪些字段？版本怎么管？配置错了怎么降级？

- 期待：配置 → 接口 → 组件/schema 渲染 → 埋点；字段含文案/图标/主题/跳转/优先级/实验；版本兼容与兜底。
- 追问：「新增一个字段，前后端谁先上？」「老客户端不认识新字段怎么办？」

### 21. **必问** 动态计算可展示标签数量

> 怎么根据宽度算能放几个？文字长度、字体加载、缩放、i18n 怎么处理？resize 时怎么重算？

- 期待：测量（canvas/离屏 DOM/getBoundingClientRect）、优先级排序、溢出省略/折叠、ResizeObserver、防抖；字体加载后重算。
- 追问：「多语言文案长度差异很大，怎么保证不抖？」「首屏测量会不会引起重排？」

### 22. 曝光埋点

> 怎么保证上报的是「真实展示」而不是「渲染了但没看到」？重复曝光怎么去重？性能怎么控？

- 期待：IntersectionObserver/可见比例/停留时长；曝光 ID 去重；批量上报；首屏延迟上报。
- 追问：「快速滑动时漏报怎么办？」「标签被折叠了算不算曝光？」

### 23. 3pd → 0 的口径

> 前端工作量从 3pd 降到 0，具体降了什么？第一次接入新标签，前端还要做什么？

- 期待：能说清「配置化覆盖了哪部分」；承认首次接入/联调/验收仍有成本。
- 警惕：把「不需要发版」说成「完全不需要前端」。

### 24. 弹窗 schema 渲染

> 解释弹窗的 schema 怎么解析？分组、高亮、跳转、埋点怎么做？用户内容会不会有 XSS 风险？

- 期待：schema → 组件映射；白名单；富文本转义/CSP；跳转协议校验。
- 追问：「schema 里带 HTML 你怎么处理？」

## 五、选品域 AI 研发提效与智能告警（12 分钟）

> 为什么要抽象成统一 CLI？鉴权、分页、限流、错误码怎么统一？新增一个平台要做什么？

- 期待：适配器模式、统一错误模型、重试/限流、配置化；新增平台只实现接口。
- 追问：「跨平台数据格式不一致，你在哪一层做归一化？」

### 30. AI 生成代码的质量门禁

> AI 改的代码，谁能合？跑哪些测试？出问题怎么回滚？有没有 AI 改坏线上代码的例子？

- 期待：人工 review、单测/回归、灰度、回滚；能讲一次失败案例。
- 警惕：只说「AI 很准」；没有门禁。

### 31. 安全与权限

> 告警助手能读代码、查发布记录、调内部 API，权限怎么控？会不会把敏感信息带进 prompt？

- 追问：「有人在告警文本里注入指令，你的 Agent 会怎么做？」

### 32. 去掉 AI 还剩什么

> 如果明天把大模型拿掉，这套系统还剩下什么价值？

- 期待：规则引擎、数据归一化、排查 SOP、平台适配仍然成立；AI 只是编排层。
- 警惕：系统价值完全依赖模型。

## 六、前端基础（15 分钟，选 8–10 题）

### 33. 事件循环（给代码）

```js
console.log('1')
setTimeout(() => console.log('2'), 0)
Promise.resolve().then(() => console.log('3'))
queueMicrotask(() => console.log('4'))
;(async () => {
  console.log('5')
  await null
  console.log('6')
})()
console.log('7')
```

**参考答案**：`1 → 5 → 7 → 3 → 4 → 6 → 2`。
追问：「微任务里再产生微任务什么时候执行？」「setTimeout 4ms 会改变顺序吗？」（不会，仍在宏任务队列）。

### 34. Promise 顺序

```js
const p = new Promise((res) => setTimeout(() => res(1), 1000))
p.then((v) => console.log(v))
p.then((v) => console.log(v))
setTimeout(() => p.then((v) => console.log(v)), 3000)
```

**参考答案**：约 1s 打两次 `1`，3s 再打一次 `1`；Promise 是状态机，值会被记住。
追问：「`Promise.race` 和 `Promise.any` 的区别？」「输的那一路会取消吗？」（不会）。

### 35. this / 箭头函数 / bind

> this 有哪几种绑定？箭头函数有什么不同？手写 bind 要注意什么？

**参考答案**：默认（严格模式 undefined）、隐式、显式、new；箭头函数取定义时外层 this，call/apply/bind 改不了；bind 返回新函数、支持柯里化、要处理 new 调用。

### 36. 原型与 instanceof

> `prototype` 和 `__proto__` 的区别？`instanceof` 怎么判断？`Object.create(null)` 的对象有 `__proto__` 吗？

**参考答案**：prototype 是函数属性，__proto__ 是对象内部原型；instanceof 沿原型链查找；`Object.create(null)` 没有原型链，也没有 `__proto__`。

### 37. 闭包与内存泄漏

> 闭包为什么会泄漏？常见泄漏场景有哪些？怎么定位？

**参考答案**：闭包长期持有外部变量；定时器、事件监听、全局缓存、脱离文档的 DOM、Promise 未结束；DevTools Memory/Heap Snapshot、Performance Monitor。

### 38. TypeScript

> `any` 和 `unknown` 的区别？泛型约束怎么写？类型收窄有哪些手段？

**参考答案**：unknown 安全，需收窄后使用；`extends` 约束；typeof/instanceof/in/字面量/自定义类型守卫。追问：「`satisfies` 解决什么问题？」

### 39. React

> 为什么不能直接改 state？`setState` 后立刻读为什么拿不到新值？`useMemo`/`useCallback` 什么时候真有用？

**参考答案**：依赖引用比较触发更新；setState 批量/异步；缓存昂贵计算与稳定引用，滥用反而增加成本。追问：「hooks 为什么不能写在条件里？」

### 40. Lynx 与跨端

> Lynx 的渲染/线程模型和 H5、React Native 有什么不同？JS 和 UI 怎么通信？首屏为什么可能更快？

**参考答案（按公开资料，允许候选人纠正）**：Lynx 采用双线程，主线程负责 UI/布局，后台线程跑 JS，减少 JS 阻塞首屏；模板 + 数据直出；与 RN 的原生组件桥接、H5 的 DOM/浏览器渲染不同。
追问：「Lynx 里怎么做动画/长列表？」「JSB 调用失败怎么排查？」

### 41. 缓存与 HTTP

> 强缓存和协商缓存分别靠什么头？`index.html` 和 `app.[hash].js` 的缓存策略为什么不同？304 是谁返回的？

**参考答案**：`Cache-Control`/`Expires`；`ETag`/`Last-Modified`；HTML 用 no-cache 保证入口更新，带 hash 的静态资源可长缓存；304 由服务端/协商缓存返回。

### 42. CORS 与 401

> 控制台同时出现 CORS 和 401，怎么区分？CORS 请求真的发出去了吗？带 cookie 时 `Access-Control-Allow-Origin: *` 为什么不行？

**参考答案**：CORS 是浏览器拦截响应，请求可能已到达服务端；401 是服务端拒绝；credentials 模式下不能通配符，必须具体 origin + `Allow-Credentials: true`。

### 43. XSS / CSRF

> 两者攻击链路有什么不同？前端分别能做什么？CSRF 只靠前端能防住吗？

**参考答案**：XSS 注入执行代码偷数据；CSRF 借用登录态发请求。前端：转义、CSP、HttpOnly、SameSite、CSRF Token、Origin/Referer 校验；CSRF 必须服务端配合。

### 44. 首屏白屏排查

> 用户反馈白屏 3 秒，你按什么顺序查？先量哪个数？

**参考答案**：DNS/TLS/TTFB → HTML → 静态资源 → JS 报错/兼容 → 接口 → 渲染/设备；先看监控与真实用户分段耗时，再本地复现。

### 45. 存储选型

> localStorage / sessionStorage / IndexedDB / Cookie 的边界？缓存 2000 条商品数据选哪个？

**参考答案**：同步/5MB/随请求/跨标签/异步大容量；2000 条选 IndexedDB，避免主线程阻塞与容量上限。
