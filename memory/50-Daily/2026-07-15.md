## 工作日志 — 键盘输入框「直接到位」版(新分支 pwa-kb-snap-height)

- **背景**:上版「跟手 + 停 180ms 补位」用户嫌补位不够直接,要「直接到位」。从最新 feature 切新分支 `personal/zz/pwa-kb-snap-height`。
- **方案**=floor 到历史最大高度(位置永远对)+ 给输入框上抬**加 CSS 过渡**,一步平滑滑到位,去掉逐帧跟手 + settle 补位。
- **改动**(未 commit):①`bridge.ts` handler 简化为 `show ? Math.max(0, lastKbFullHeight - KEYBOARD_TOP_GAP) : 0` 一步设终值,删 `kbSettleTimer`;②三处输入区 transform 过渡 `transform 0.04s linear` → `transform 0.2s cubic-bezier(0.2,0,0,1)`(`Chat/index.tsx` / `TutorialChat/index.tsx` / `ChatInputBarPreview/index.tsx`,`--kb-height` 消费点)。
- **权衡**:二次弹出已有历史高度 → 一来就滑到正确位;首次弹出无历史值,随 native 累积,若那次少报会略偏低、之后即修正。tsc 0 / lint 0,**待真机验观感**。
- **消费点定位**:`--kb-height` 由三处 `translate3d(0, calc(-1 * max(0px, var(--kb-height) - var(--nav-height))), 0)` 消费;`bridge.ts` 只负责设 `--kb-height`/`--nav-height`。
