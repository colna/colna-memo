- **vela-tts**：`CloneVoiceRequest` 增加可选 `ref_text`；有值则原样转发，空则仍传空以走上游 ASR；克隆优先 `POST /profiles`，404/405 再试 `/api/profiles`。

- **admin**：克隆对话框增加「参考文案（可选）」；`cloneVoice(..., refText?)` 有值才写入表单。
- **重启**：本机 `vela-server` 已重建并重启（VoiceStudio adapter）。
- **自测**：
  - 单测 `voicestudio_clone_posts_multipart_to_profiles` 通过（断言转发非空文案）。
  - 经 `/v1/voices/clone`：带 `ref_text` → `ready`；不带 `ref_text` → profile 也能建出，但上游 profile 的 `ref_text` 仍为空。
