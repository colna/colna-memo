## 工作日志 — 22:45 koda 聊天页消息列表抽成 memo 组件(对齐 iris 手感)

- **做了什么**:在 `feat/koda-ce`(PR #394)上,把 `apps/koda/src/app/chat/[id].tsx` 里内联的聊天消息 `FlatList` 抽成独立组件 `apps/koda/src/components/chat/chat-message-list.tsx`(`memo(ChatMessageList)`)。组件内部保留 inverted 布局、memoized `contentContainerStyle` 与 `renderItem`、greeting 面板作为 header;导出 `THREAD_BOTTOM_PADDING`。屏幕侧删掉 `invertedRows` / `listContentStyle` / `renderChatRow` 三个 memo,新增 `bottomPadding` useMemo,删除无用 `styles.list` / `styles.listFlex` 及 `Spacing` import。
