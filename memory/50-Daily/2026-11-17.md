## 工作日志 — 00:39 Onia 鉴权配置加固

**项目**：Onia（Rust server / Kotlin chat-agent）

- **做了什么**：
  - `ONIA_JWT_SECRET` 改为必填且至少 32 位，拒绝旧开发默认值；仅 `ONIA_ALLOW_INSECURE_DEV_DEFAULTS=true` 时允许本地弱配置。
  - 管理员 bootstrap 改为显式开关 `ONIA_BOOTSTRAP_ADMIN_ENABLED`，默认不创建。
  - 配置 `ONIA_CHAT_AGENT_URL` 时强制要求 `ONIA_CHAT_AGENT_SECRET`；chat-agent 启动时强制要求密钥，`/v1/replies`、`/v1/greetings`、`/v1/traces` 全部校验 `X-Onia-Agent-Secret`。
  - CORS 新增 `ONIA_CORS_ALLOWED_ORIGINS`；未设置时保持本地 mirror 并打 warn，设置后只允许显式 origin。
  - `.env.example` 改为安全默认；README 补本地/生产配置说明；本机 `.env` 增加两个 dev 开关保持本地可运行。
- **为什么**：原默认 JWT 密钥、默认管理员和 chat-agent 可选鉴权会让生产鉴权失效。
- **结果**：
  - `cargo check -p onia-server` 通过；`cargo test -p onia-server --lib config::tests` 6 passed。
  - `apps/chat-agent/./gradlew test` 通过；实测 `/health` 200，无密钥 `/v1/traces/*`、`/v1/replies/generate` 均 401，带密钥 traces 返回 404（预期）。
  - 无密钥启动 server 报错 `ONIA_JWT_SECRET is required...`；无密钥启动 chat-agent 抛 `ONIA_CHAT_AGENT_SECRET must be set`。
  - 全量 server 启动被既有 migration 7 checksum 冲突拦住（`0007_automation_settings.sql` 本地修改后与已应用版本不一致），与本次改动无关，未处理。
- **关键文件**：`crates/onia-server/src/config.rs`、`crates/onia-server/src/lib.rs`、`crates/onia-server/src/pipeline.rs`、`apps/chat-agent/src/main/kotlin/io/onia/chatagent/Application.kt`、`.env.example`、`README.md`
- **沉淀**：生产部署检查项见 README；migration checksum 问题待单独处理。
