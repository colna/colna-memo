## 工作日志 — 14:16 Google 登录改为自定义 scheme，真机跑通

- **问题**：prod 包（11:40 版本，loopback 回调 `http://127.0.0.1:<port>`）在 Xiaomi/OPPO 上授权完成后报 `ERR_CONNECTION_TIMED_OUT`。
- **根因**：Custom Tab 打开后 App 进后台被系统冻结，loopback socket 仍在 LISTEN 但 Dart isolate 不处理请求。证据：超时时 `nc 127.0.0.1:40707` 超时；`am start` 切回前台后同一端口立即返回 200。
- **方案**：改用 OAuth authorization code + PKCE + reverse-DNS 自定义 scheme（`com.googleusercontent.apps.<desktop-client-id>:/oauth2redirect`），App 用 `app_links` 收 code，再调服务端 `/v1/auth/google/exchange` 换 id_token（secret 不上端）。
- **实测排除**：Android client ID（`uvct4…`/`mj6f…`）在 authorization endpoint 直接 `401 invalid_client`（Google 只允许 Android client 走 Play Services）；Desktop client + 任意 `onia://` scheme 也报 invalid_request。只有 Desktop client + 自己的 reverse-DNS scheme 被接受。
- **改动**：`google_auth.dart`（deep link + exchange）、`onia_api.dart`（googleExchange）、`kinds.dart`、`login_screen.dart`、`AndroidManifest.xml`（Desktop scheme intent-filter）、`ios/Runner/Info.plist`（CFBundleURLTypes）、`config/dev.json`+`prod.json` 改回 Desktop client ID、`defaults.dart` 注释。
- **验证**：`flutter analyze` 干净、`flutter test` 114 passed；OPPO `f7031061`（浏览器已登录 Google 账号、设备本身无系统 Google 账户）走完「使用 Google 继续 → Chrome Custom Tab → 继续 → 自动跳回 App」，进入工作台，Me 页显示 richardzhang1999@163.com，Device online。
