## 工作日志 — 15:19 定位 SUBMIT_STORY「烧录任务查询失败 HTTP 502」

- **现象**：`SUBMIT_STORY@1` 报 `STORY_PUBLISH_FAILED: 烧录任务查询失败：HTTP 502 error code: 502`；`dom_snapshot` 停在 IG inbox，说明还没进发布。
- **定位**：
  - 该文案只在 `createStory.js`（`callBakeApi` 轮询分支）抛出：`GET /script/bake-story-video/:jobId` 返回非 success；报错 body `error code: 502` 是 Cloudflare 纯文本错误页，不是 Nest JSON → 请求没到应用或应用不可用。
  - 不是烧录任务本身 failed（那会带 `job.error`）。
  - 现场实测 `https://social-proxy-api-dev.sitin.ai/script/bake-story-video/<uuid>`：能返回 `404 {"message":"bake job not found"}`，但极不稳定——6 次里 3 次连接超时，成功耗时 1–5.6s；根路径 `/` 连续超时。判断 dev origin 间歇性不可用/过载（Cloudflare 转发失败 → 502）。
- **代码层放大因素**：
  - 轮询对任何非 success 立即 throw，无 5xx/超时重试，一次抖动就整条 Story 失败。
  - bake job 存在进程内 `Map`，重启或多副本会丢 job（随后 404）。
- **待办**：① 查 dev pod 重启/CPU/内存（ffmpeg 烧录时是否 OOM）；② 给轮询加 3–5 次 5xx/网络重试；③ 若 dev 多副本，job 状态需落 Redis。
