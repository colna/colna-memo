## 工作日志 — 19:25 sitin-next Chat 键盘弹起顶起底栏修复

- **做了什么**:`sitin-next / app-pwa` 修 Chat 页键盘弹起时底部 TabBar 被顶到键盘上方的问题。改动全在 `packages/app-pwa/src/components/TabLayout.tsx`(通用底栏外壳,`/`、`/earnings`、`/chat`、`/live`、`/me` 共用)。
- **为什么**:`index.html` 里 viewport meta 配了 `interactive-widget=resizes-content`,Android Chrome 键盘弹起时 layout viewport 一起被压缩,`h-full` 容器缩短,TabBar 贴到新的底部(键盘上沿),再把 ChatFooter 一起顶起,视觉上"输入框和 nav 一起飞起来"。
- **结果**:PR [#597](https://github.com/presence-io/sitin-next/pull/597) 已 merge 到 `feature/sitin4.0`(merge commit `6b6a68386`)。本地 + 远端 `personal/zz/pwa-chat-tabbar-keyboard` 已删。
- **两次迭代**:
  - **v1**(`4b33ddfc0`):`:has(:focus)` 纯 CSS 隐藏 TabBar。看似优雅,但漏了"键盘下拉手势 / Android 系统返回收起键盘"这类**输入框仍 `:focus`、键盘已消失**的场景 → TabBar 一直藏着,底部空一大块。
  - **v2**(`84874c8e3`):`visualViewport.resize` + baseline-max 记录见过的最大高度,当前高度比 baseline 少 >150px 判定键盘展开,涨回 baseline 判定收起。彻底与 focus 状态解耦。150px 阈值挡掉 URL bar 展开/收起(~60px)误判。
- **关键 diff**:
  ```tsx
  function useKeyboardOpen(): boolean {
    const [open, setOpen] = useState(false);
    useEffect(() => {
      const vv = window.visualViewport;
      if (!vv) return;
      let baseline = vv.height;
      const onResize = () => {
        if (vv.height > baseline) baseline = vv.height;
        setOpen(baseline - vv.height > 150);
      };
      vv.addEventListener("resize", onResize);
      return () => vv.removeEventListener("resize", onResize);
    }, []);
    return open;
  }
  ```
- **踩坑 & 决策**:
  1. `interactive-widget=resizes-content` 让 layout viewport + visual viewport **一起缩**,所以 `visualViewport.height` 和 `window.innerHeight` 都被压小,不能靠比这两者判定键盘 —— 必须比 baseline。
  2. pre-push hook 跑全库 `build+test`,`business-minerva-*` / `app-social-proxy-server` 有既有失败(基线 `feature/sitin4.0` 也挂),两次推送都要 `--no-verify`。用户 CLAUDE.md 只禁 `git commit --no-verify`,pre-push 绕过已征得同意。
  3. `TabLayout` 是 5 个 tab 的通用外壳,改在这里等于全局生效;主流 chat app(WhatsApp、微信、Instagram DM)也是任意 tab 键盘弹起隐藏底栏,方案通过。
- **沉淀**:`30-Resources/troubleshooting/mobile-keyboard-and-viewport.md` —— visualViewport / interactive-widget 三档、`:focus` vs 键盘可见的差异、baseline-max 检测模板。
