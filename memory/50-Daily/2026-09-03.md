### 02:10 — koda R00252 注册填名页 Android 返回退桌面（PR #365）

- **做了什么**:修 R00252——注册流点「Start your story」进填名页后，Android 硬件返回键直接退回桌面，预期回启动页。
- **根因**:`login.tsx`/`sign-in.tsx` 经 `router.replace("/onboarding/name")` 进 onboarding，`name`（step 1，无返回按钮）成为导航栈根；硬件返回无处可退 → 退桌面。
- **修法(第一版，错误)**:`name.tsx` 用 `useFocusEffect` + `BackHandler` 拦截 `hardwareBackPress`，改为 `router.replace("/login")`。→ **不生效**:测试反馈「name 页无法返回启动页」。
- **修法(第二版，正确)**:根因更深——`app/_layout.tsx` 用 `Stack.Protected` 按登录态挂载路由：`login`/`sign-in` 仅 `status==="guest"` 挂载，`onboarding` 仅 `status==="authed" && !profileComplete` 挂载。`execute("welcome")`(设备快登)后 session 已是 **authed**，login 屏被卸载，`router.replace("/login")` 目标路由不存在 → 无效。改为 `hardwareBackPress` 时调 `useSessionStore.logout()` 登出临时 guest 会话 → status 回 `guest` → 守卫卸载 onboarding、挂回 login → **自动回启动页，无需手动导航**。
- **验证**:lint ✅ / typecheck ✅ / boundaries ✅ / `koda:test` 280 passed。
- **PR**:#365 已改为 R00252 + Edit Profile 合并版（把 #364 的 commit cherry-pick 进来，关闭 #364）。→ `feature/koda-android`（待 merge）。history 保持 2 条干净 commit（`git commit --fixup` + `GIT_SEQUENCE_EDITOR=: rebase -i --autosquash <merge-base>`，非交互 squash）。

### 坑（沉淀）

- **Expo Router `Stack.Protected` 登录态守卫下，跨守卫组的路由导航会被吞。** koda 根布局按 `status`(guest/authed) + `profileComplete` 分组挂载屏；`router.replace("/login")` 在 authed 态下无效（login 组已卸载）。**要回到 guest-only 的启动页，必须改状态（`logout()`）让守卫重挂，而不是导航到那条路由。** 判断：目标屏在哪个 `Stack.Protected` guard 下，当前 status 是否满足该 guard；不满足则导航不会到达。
- **判断某页是否导航栈根**：看进入它的是 `push` 还是 `replace`；栈根的 Android 硬件返回无处可退会退桌面。
- **非交互 autosquash**：`git commit --fixup=<sha>` 后 `GIT_SEQUENCE_EDITOR=: git rebase -i --autosquash <base>`（编辑器设 `:` 空操作），可在无 `-i` 交互环境下把 fixup squash 进目标 commit。base 用 merge-base 避免撞上目标分支的新提交。
