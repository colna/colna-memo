## 工作日志 — sitin-rn PR #465 merge（Luka 划卡页按 Figma 重做）

合并提交 `8c96b1a2` → `feature/luka-ios`，19 个提交。按四要素记：

**做了什么**

**遇到什么问题 / 怎么解决**（这次踩的坑，都值得记）

1. **换卡闪一下**。两处叠加：① `key={候选人 id}` 让每换一张整棵子树卸载重建，**明明已经在背面加载好的照片被扔掉重来**，那一两帧画的是 `loadingColor` 占位色；② `translateY.value = 0` 写在 `advance` 里，而 **shared value 的写入比 React commit 早一帧生效** —— 那一帧 index 还是旧的、transform 已归零，刚飞出去的卡原地满不透明画了一帧。
   → 改成**两个槽轮流当正面**（`index % 2`），槽的 key 稳定，背面槽转正时演的还是同一个人、同一棵子树；归零改成归**刚转到背面**那个槽的零，放进 `useEffect([index])`。
2. **槽复用把 `greeting` / `favourite` 留给了下一个人**（1 的直接回归）。`greeting` 置 true 后代码里没有任何地方置回 false，于是「对 A 打过招呼后，轮到这个槽的每个人 Say hi 都点不动、卡片也点不开」。
   → 给 `CandidateCard` **按人加 key**。槽只在转到背面时才换人，所以只有被完全盖住的那张重建，正面那张照旧复用、照片不重解码 —— 修状态泄漏又不把闪动带回来。
3. **标签一行放不下切出半颗**。`flex-row`（不换行）+ `overflow: hidden`。设计稿帮不上忙：它的示例数据全是短词（Nature/Food/Art/Dogs/Fitness 正好排满），从没碰到过溢出。
   → 加 `flex-wrap` 但保留固定行高 + 裁剪：放不下的整颗掉到第二行，而第二行完全在裁剪框外 → 要么完整、要么不出现，卡片总高不变。
4. **重写容器时把旧容器攒下的守卫一起丢了**（`/code-review` 抓出来的，10 条全属实）：首卡从不上报展示、游标不夹范围、飞出途中第二次触摸吞掉这次划走、手势每次渲染重建、`remove()` 丢了上报、震动阈值沿用旧容器的 `0.05`（新容器进度已归一化，划走线是 `1`，等于手一动就震）。

  3. `?pet=0` 一键关掉两处（Say hi 自动回到 👋），方便和上一版对比。
- **为什么这样放**：09-09 已经删过「鸡蛋横幅 `PetPerchBanner`」和「宠物孵化页」，说明**纯装饰的宠物露出会被砍**。所以这两处都挂在真实功能上——共同点条承载 deck 上那张 Common Ground 粉卡的内容，Say hi 是这一页的主动作。没有 `commonGround` 数据时整条不渲染。
- **坑：「探出」要靠层级而不是位移**。子元素永远画在父元素 background 之上，所以小崽放进条里只会「站在条上」。改法：条的底色用 `::before` 画（`z-index:1`），小崽 `z-index:0`、文字 `z-index:2`，小崽下半身才会被底色盖住。父元素加 `isolation:isolate` 免得 z-index 泄到外面。
- **代价**：首屏多了约 100px，`Her moments` 从「完整可见」变成被底部按钮截掉一半，页面开始需要滚动（折叠导航因此才真正生效）。要保住首屏原样，可以把条挪到 moments 之后。
- **验收**：headless 截图逐轮比对，`?pet=0` 与上一版一致；点击态截到了 ❤️ 飞出 + `Sent ✓`。
