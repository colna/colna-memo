## 工作日志 — 11:35 Luka：Edit profile hub 按新稿重做（分组卡 + 右上角大仓鼠）

- **素材**：`play-mac.mov`（1440×1440 ProRes 4444 + alpha、193 帧、8.04s、483 MB）→ 480×480 HEVC-with-alpha、2.1 MB。本机 ffmpeg 7.1.1 编不出可用的 alpha，脚本自动走 ProRes 中间件 + `avconvert` 并复核透明。母版移出仓库到 `~/WORK/luka-pet-masters/play-mac-master.mov`（`ls -lh` 里 483 MB 的未跟踪文件不能留在 repo）。
- **第一版在模拟器上是坏的**：仓鼠背后一个灰方块。根因在母版 —— 整块画布带一层 alpha 1–15 的软阴影（占 43% 像素），压在奶油底上就是画布边界。于是给共享脚本加了 `--alpha-floor <N>`（`scripts/compress-mov.sh`，成片与包围盒扫描都先抹平），顺带踩到第二个坑：`lut` 的 `val` 是**源位深**，ProRes 4444 的 alpha 是 10/12 位的，阈值前必须先 `format=gray` / `format=bgra` 落到 8 位。沉淀进 [[mov-alpha-compression]] 的「坑六」。
- **落点常数**：仓鼠在片段里会左右晃（第 50–55 / 161–165 帧还把 MacBook 伸到左边），所以 `RIGHT_PAD_RATIO` 取**全 193 帧的并集** 0.10 —— 先按中间帧的 0.17 试过，右肩被屏幕切掉一块。`PET_SIZE 156`（≈130pt 的仓鼠）与稿子量到的 130pt 对得上。
