### 11:40 · sitin-rn：luka 注册 name 屏进入「闪两下」修复（已提交并 push）

- **做了什么**：修用户报的「进入输入 username 页时，会闪两下才进入」（注册第一步 `apps/luka/src/app/onboarding/name.tsx`）。
- **排查（模拟器录屏逐帧，非读代码猜）**：iPhone X (11 Pro eq) 临时把根布局 onboarding 组守卫放宽为 `true`，`luka://onboarding` 深链复现 → `simctl io recordVideo` 录屏 → ffmpeg 抽帧 → `magick compare -metric AE` 逐帧差。深链后：17.2–17.77s 转场滑入（250 万 px/帧）、17.8–18.3s 键盘渐弹、**18.8s 单帧 20.5 万 px 突变**（变化集中在 y 20%–60%，正是 eyebrow / 仓鼠行 / 输入区）。
- **两处根因**：
  1. `scaffold.tsx` 的 `compact = keyboardAdaptive && keyboardVisible`：name 屏 `autoFocus` 立刻弹键盘，但折叠态要等 `keyboardVisible` 翻转才生效——这个翻转由 JS 状态驱动、比 OS 键盘动画晚几百 ms 落地，转场刚稳时仓鼠行**整块卸载** + eyebrow 折叠 + CTA padding 突变，一帧内完成 = 最刺眼那一下。
  2. `onboarding/index.tsx` 的 `<Redirect>` **渲染 null**：登录成功守卫翻转挂载本屏、与 replace 到 name 之间会露 1–2 帧窗口底色（白/黑）。
- **修法（3 文件）**：
  - `scaffold.tsx`：加 `keyboardHasAppeared` ref，`compact = keyboardAdaptive && (keyboardVisible || !keyboardHasAppeared.current)`——`keyboardAdaptive` 屏**首帧即折叠态**，键盘弹起无跳变；键盘收起过之后照旧展开。eyebrow 初值 `useSharedValue(compact ? 0 : EYEBROW_HEIGHT)`、CTA padding 改跟 `compact`。查过 `keyboardAdaptive` 三个消费方（onboarding/name、onboarding/location、edit-profile/name）**全部带 autoFocus**，语义升级无副作用。
  - `onboarding/index.tsx`：`Redirect` 包一层 `flex-1 bg-background`（与 name 屏同奶油底）。
  - `_layout.tsx`：根 View 加 `bg-background`，兜住 auth 守卫换组时的容器交接空隙。
- **验证**：同一深链路径重录 → 20.5 万 px 单帧突变消失，最大帧差降到 1.6 万（仅键盘渐入/噪声）；顶部区域转场早期已是奶油底。`tsc --noEmit` 0、`biome check` 3 文件干净。
- **关键命令**：`xcrun simctl io <UDID> recordVideo --codec h264 --force`（**必须 `kill -INT` 优雅停**，强杀会丢 moov、且可能残留 host 录制占用——本次踩过，重启模拟器才清掉）；`ffmpeg -ss 16.5 -t 3 -vf fps=30`；`magick compare -metric AE a.png b.png null:`。
- **提交**：`616339e6b` `fix(luka): 注册 name 屏进入不再闪两下` → `origin/feature/luka-ios`；pre-commit biome、pre-push boundaries + luka typecheck 全过。`_layout.tsx` 里并行会话的 `ensureTrackingConsent`（ATT 清单 DATA-02）用 `git add -p` 只暂存我这一处、未夹带；根目录 `-` 与 `docs/app-store-checklist-review.md`、`assets/onboarding/` 等并行产物也没扫进来。
- **沉淀**：RN 键盘自适应屏若 `autoFocus`，**首帧就渲染折叠态**，别等 `keyboardVisible` 翻转（JS 状态滞后于键盘动画，转场期暴露成布局跳变）；`Redirect` 落地屏要垫同色背景，否则守卫换组时露窗口底色。
