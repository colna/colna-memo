## 工作日志 — 15:10 sitin-next 探针自拍「总是超时」根因定位 + 前端修复

- **做了什么**:排查 sitin-next【消息金】自拍探针「正常完成却总被后端记超时、且只给了文字消息奖励」。跨前后端(`sitin-server/chat-service-*` + `sitin-next` app-pwa)通读链路,拿到一份 dev vconsole 完整复现日志定位根因,并在 `feature/sitin4.0.1`(拉进 `sitin-next2`)修复前端。
- **为什么**:探针 7419 从没被清成 completed → 后端统计恒为超时;钱走了消息任务 7418(`reply_type=probe_image`)。
- **根因(前端)**:`PhotoTaskDrawer.done()` / `VoiceTaskDrawer.send()` 里 `onSent?.(...)` 之后**无条件同步调 `onClose()`**,而父层 `onClose=dismissPhoto=dismiss(report=true)` → 每次成功发送都**多打一发 `pwa_chat_task_abandoned` + `reportTimeout(PROBE, level=GREEN)`**。日志实锤:audit passed → `task_abandoned 7419` + `ReportTimeout{level:1,taskType:2}` → 之后自拍才真正上传发出。
- **根因(后端,未改·另一个仓)**:① `reportTimeout` grpc 完全忽略 `taskType`,对 PROBE 也 `setEarningsPaused`+发假 `TASK_TIMEOUT_YELLOW`,且不碰 probe 实体;② `handleOutboundMessage` 不读 `cloudCustomData.replyKind`,只清 pending 消息任务并付其奖励;③ `completeProbeDone` grpc 全工作区零调用方 → probe 永不 completed。
- **结果**:改 4 文件——`done()/send()` 改 `const ok = await onSent?.(...); if (ok !== false) onClose();`(useLockFn 防连点);`ProbeTaskDrawers` 加模块级 `sentProbes` 集,`handlePhotoSent/handleVoiceSent` 成功打标并 `return ok`、不再自己关抽屉,`dismiss` 的 report 块加 `!sentProbes.has(id)` 守卫使「已发送」的 onClose 静默关(不放弃/不上报);`index.tsx` 的 `onSendImage/onSendVoice` 补 `return ok`。语义:发送成功静默关、失败保持打开可重试。**未 commit/未 push**(待用户批准)。
- **关键命令 / diff**:`sitin-next2` 切 `feature/sitin4.0.1`(HEAD 22dd9b77);`pnpm install`(19s)→ `pnpm --filter "@heyhru/app-pwa^..." build` → `tsc --noEmit` **0 err**、`eslint` 改动文件 **0 err**。app-pwa 无测试设施(无 vitest/RTL),暂靠 dev 预览 + 分支自带 console.log 验证(改后成功发送不再打印 `report_abandoned`)。
- **沉淀**:根因+修法已单独写到 `30-Resources/troubleshooting/sitin-next-probe-selfie-timeout.md`;后端契约见既有 `sitin4.0-anomaly-probe-backend`。
