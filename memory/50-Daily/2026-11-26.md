### 10:25 排查 Pixel 6 连 presence-5g 显示「网络受限」

- **现象**：用户反馈当前 USB 连接的 Pixel 6，连办公室 `presence-5g` 时系统提示网络受限。
- **做法**：`adb devices` 确认设备；`adb shell cmd wifi status` / `dumpsys connectivity` / `dumpsys wifi` 查状态；`adb logcat -d | grep NetworkMonitor` 抓验证日志。
- **结果**：Wi-Fi 实际正常——IP `192.168.3.110/23`，BSSID `54:10:2e:85:b0:a0`，5805MHz / 11ax，RSSI -61~-63，链路 390-487Mbps，`Restricted: false`；手机 ping 网关/DNS 0% 丢包，`http://connectivitycheck.gstatic.com/generate_204` 返回 204。
- **根因**：Android 原生网络验证会同时探测 `https://www.google.com/generate_204` 和 `http://play.googleapis.com/generate_204`，这两个域名在大陆超时；国内可达的 gstatic HTTP 探测成功，于是判定为 `PARTIAL_CONNECTIVITY`（部分连通），系统 UI 显示「网络受限」。不是路由器限速/黑名单。
- **其他**：手机时区为 `America/New_York`（时间数值正确：EST 21:24 = 北京 10:24）；手机在跑 Clash Meta VPN（`com.github.metacubex.clash.meta`，tun0），但 Wi-Fi 验证请求绑定 wlan0 直连，VPN 不影响该判断。
- **未做**：未改 `captive_portal_*` 设置，待用户确认是否改成国内验证端点。
- **沉淀**：Android 「网络受限」先看 `dumpsys connectivity` 的 `PARTIAL_CONNECTIVITY` 与 `NetworkMonitor` 日志，区分「真不通」和「Google 验证端点被墙误报」。

### 14:55 Hindsight 本地接入：服务 + colna-memo 知识库 + opencode

- **做了什么**：把 Hindsight（agent 长期记忆服务）跑在本机 Docker，建 knowledge bank `colna-memo` 灌入 408 篇 Markdown，并接到 opencode。
- **起服务**：镜像走 `ghcr.nju.edu.cn/vectorize-io/hindsight:latest`（直连 ghcr 仅 ~0.35MB/s，NJU 镜像 ~0.9MB/s）；容器名 `hindsight`，端口 8888/9999，数据卷 `hindsight-data`；启动脚本 `~/.config/hindsight/start.sh`。
- **模型配置**：LLM = `deepseek/deepseek-flash`（key 从 opencode `auth.json` 读）；embedding = local `hindsight-ai/hs-embed-1`（384 维）；`HF_ENDPOINT=https://hf-mirror.com`（本机直连 huggingface.co 超时）；reranker 关成 `rrf` 省内存。
- **坑（OOM）**：knowledge bank 默认 embedder 是 `google/embeddinggemma-2`（768 维、fp32 约 1.2GB），与 hs-embed-1、reranker 同时常驻，Docker 分配 8GB → API 被 OOM kill 两次。处理：关 reranker、KB `BATCH_SIZE=2`/`MAX_IN_FLIGHT=1`、灌库改成逐篇同步提交。
- **灌库脚本**：`~/.config/hindsight/ingest-colna-memo.py`；按目录打 tag（10-Projects/30-Resources/50-Daily…），document_id = 目录__文件名；knowledge bank 只做 embedding，不花 LLM；支持中断续传（跳过 ready）。
- **opencode 接入**：`npx @vectorize-io/hindsight-coding-agents install opencode2 --server self-hosted --api-url http://localhost:8888`，在 `~/.config/opencode/opencode.json` 写入 `plugin`，运行时在 `~/.hindsight/coding-agents`；每仓库一个 memory bank（`coding-agent::<repo>`），自动从 git 历史 + 会话 retain。
- **colna-memo 检索**：opencode MCP 新增 `hindsight-kb`（remote，`http://localhost:8888/mcp/kb/colna-memo/`），工具 search/list/get/ingest knowledge bank。
- **成本/内存调整**：给 4 个 coding-agent bank 设 `enable_observations=false` + `enable_auto_consolidation=false`（8GB 容器扛不住，且每轮 consolidation 约 2 万 input token）。
- **备份**：`~/.config/opencode/opencode.json.bak-hindsight-20261126-1403`。
