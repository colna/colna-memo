## 工作日志 — 02:55  调研:minerva-server 接入 Nacos(为实时算小美保底补贴)

- Vert.x `ConfigRetriever` + 外部依赖 `pserver-core` 的 `NacosConfigUtils.initConfig(vertx, dataId, namespace)`,`retriever.listen` 热更,合成校验过的 Snapshot(`PwaTierConfigLoader`)。

**保底补贴公式(dora `PwaTierGuaranteeService`)**:
- 预计日补贴 = `今日GoLive分钟 < daily_required_golive_minutes ? 0 : max(0, (周末?weekend:weekday)_daily_floor − 今日含加成视频收益)`。

**Node 侧接法(官方 `nacos` SDK 已核实)**:`new NacosConfigClient({serverAddr, namespace[, username/password | accessKey/secretKey], transport:'grpc'|'http'})` → `ready()` → `getConfig(dataId, group)` / `subscribe({dataId,group}, cb)` / `publishSingle`。

**连接结论**:用户定「**集群内免密**」→ minerva 与 MSE Nacos 同 k8s 集群内网直连,**不传 AK/SK/账密**,只需 `serverAddr + namespace`,由部署 env 注入(同 dora)。
