## 工作日志 — 02:55  调研:minerva-server 接入 Nacos(为实时算小美保底补贴)

**起因**:小美详情「预计日补贴」显示 `—`(缺失)。根因:minerva 从 dora 的 `pwa_tier_guarantee_daily` 表读,当天保底 job 没跑到该用户就没行 → null。要实时算(像今日视频收益那样),需 dora 的保底参数,而这些参数在 **Nacos**。

**dora 怎么用 Nacos(线上 feature/server)**:
- 阿里云 **MSE 托管 Nacos**,client `nacos-client 2.4.3`(Nacos 2.x,默认 grpc 9848)。KB `30-Resources/sitin-server-backend.md` 也记了「新 worker 走 Nacos(阿里 MSE)」。
- Vert.x `ConfigRetriever` + 外部依赖 `pserver-core` 的 `NacosConfigUtils.initConfig(vertx, dataId, namespace)`,`retriever.listen` 热更,合成校验过的 Snapshot(`PwaTierConfigLoader`)。
- **config namespace = `dora-dev` / `dora-prod`**(本仓 `NacosUtils.getCAINameSpace()`)。⚠️ `dora-dev-k8s` 是 `Application.java:273` 的 **Hazelcast k8s namespace,不是 Nacos**,别混。
- group 未显式传 → `DEFAULT_GROUP`。dataId 如 `pwa_tier_benefit_config`/`_rule_config`/`_runtime_config`/`global_db_config`/`common_config`(JSON)。
- serverAddr/鉴权在 pserver-core + k8s env(dora-k8s-config),本仓/gradle 缓存都没有。

**保底补贴公式(dora `PwaTierGuaranteeService`)**:
- 预计日补贴 = `今日GoLive分钟 < daily_required_golive_minutes ? 0 : max(0, (周末?weekend:weekday)_daily_floor − 今日含加成视频收益)`。
- Nacos `pwa_tier_benefit_config.xiaomei` 字段+默认:`daily_required_golive_minutes=120`、`weekday_daily_floor=$80`、`weekend_daily_floor=$120`、`weekly_required_golive_minutes=600`、`weekly_guarantee_floor=$500`、`weekly_guarantee_cap=$500`。注释标「Nacos 可调」→ 不能硬编码默认(运营改了会算错)。

**Node 侧接法(官方 `nacos` SDK 已核实)**:`new NacosConfigClient({serverAddr, namespace[, username/password | accessKey/secretKey], transport:'grpc'|'http'})` → `ready()` → `getConfig(dataId, group)` / `subscribe({dataId,group}, cb)` / `publishSingle`。

**连接结论**:用户定「**集群内免密**」→ minerva 与 MSE Nacos 同 k8s 集群内网直连,**不传 AK/SK/账密**,只需 `serverAddr + namespace`,由部署 env 注入(同 dora)。

**方案(待用户「开」)**:新建 `packages/server-plugin-nacos`(仿 server-plugin-redis)封装 client+Fastify 插件挂 `app.nacos`,启动读 `pwa_tier_benefit_config` 进 snapshot + subscribe 热更;`config.ts` 加 `NACOS_SERVER_ADDR/NACOS_NAMESPACE/NACOS_GROUP`(留空=关);pwa-pool 用它实时算日/周补贴,替掉读 `pwa_tier_guarantee_daily`。部署需运维给 NACOS_SERVER_ADDR 实际值 + 确认 namespaceId=dora-dev + grpc 9848 连通。

**踩坑复用**:①minerva 现有「Nacos」(business-minerva-transactions import-from-nacos)是**人工上传 JSON 入库**,不是实时客户端,别当成已接入。②dora 的 config namespace 是 `dora-dev` 不是 `dora-dev-k8s`(后者是 Hazelcast)。③MSE Nacos 集群内可免密,集群外才要 AK/SK。
