## 工作日志 — 16:20 真机残留代理清理

- **做了什么**：清除 Android 真机 `6bdc90d6`（24031PN0DC / aurora）上残留的全局 HTTP 代理。
- **为什么**：用户反馈手机无法上网。排查发现是此前 IG 真机测试链路设的
  `settings put global http_proxy 127.0.0.1:7897` + `adb reverse tcp:7897`，reverse 断开后
  设备所有流量仍被指向 `127.0.0.1:7897`，导致全面断网。
- **命令**：
  - `adb -s 6bdc90d6 shell settings put global http_proxy :0`
  - `settings delete global global_http_proxy_host / _port / _exclusion_list / global_proxy_pac`
  - `adb -s 6bdc90d6 reverse --remove-all`
- **结果**：读回 `http_proxy=:0`、host/port=null；`ping 223.5.5.5` 3/3 通（约 40ms）。
- **备注**：`:0` 是 Android 关闭全局代理的标准标记；已开着的 app 可能缓存代理，需 force-stop 重开。
