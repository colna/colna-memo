## 工作日志 — 00:xx 整理 2.6MM 小豆实色 221 色马克笔色卡

- **背景**：用户发来 1/30 页色卡照(9 大色系:A/B/C/D/E/F/G/H/M,共 221 色号),要求整理清单并提取每色 hex。
- **首次尝试受阻**：第一张图片下载后临时文件目录被清空,`PIL.Image.open` 报 `FileNotFoundError`。让用户重发后拿到 `img_v3_0213g_096d5b41-...png`(原图 1080×2400)。
- **采样策略迭代 3 次**：
  1. v1:窗口 12×12 直接取平均 → **被色号白字污染**(A01 得 `#a19e84` 偏灰绿,不是浅黄)。
  2. v2:过滤 `min(R,G,B) > 235` 的近白像素后取平均 → 有改善但仍偏灰(A01 `#cac7ac`)。
  3. v3 ✅:采样点 y 方向下偏 8 像素避开居中的色号文字,再过滤白像素、**每通道取中位数**,A01 得 `#f1edce`,合理。
- **关键定位参数**(原图坐标):
  - 列 x 中心:A=68 B=188 C=303 D=420 E=536 F=649 G=764 H=880 M=993
  - 首格中心 y=948,格高 step≈24.4(按 B 列 32 格拟合)
  - 采样窗口 16×16,y_offset=+8,每通道中位数,过滤 `min(R,G,B)>230` 的白色像素
- **色号数与标题匹配**:各列色号数 26+32+29+26+24+25+21+23+15 = **221**,与标题「221 色全色」一致。顶部数字(24/28/24/17/22/18/17/21/9=180)含义不明,可能是某种子分类,与实际色号数不同。
- **产物**:`30-Resources/marker-2.6mm-221colors.md`,含色系概览表、9 张分色系表(色号 / HEX / RGB / 内联色板)、采样脚本说明。也复制到 `OUTPUTS_DIR` 传回飞书。
- **精度声明**:采样自屏幕显示的色卡照片,受屏幕色域、印刷偏色、图片压缩影响,与实物笔色可能有 5-15% 偏差;用于原型/草图选色够用,严格配色以厂家官方色值或实物为准。

## 工作日志 — 00:xx 新建 skill `marker-pixelize`

- **需求**:用户想要「把图片降采样成 N×N 格,每格找马克笔色卡最近色号,输出可涂色的格子图」。
- **交互确认**:AskUserQuestion 确认了 4 个关键决策:装到项目 `.claude/skills/`、只输出「带色号标注的大图 PNG」(不要 TXT/CSV 网格、不要单独的预览 PNG)、长宽比处理**中心裁剪成正方形**、色板固定用 221 色(不做 --palette 通用参数)。
- **产物**(3 个文件,40 KB):
  - `.claude/skills/marker-pixelize/SKILL.md` — 触发规则、参数、注意事项。**强调不要给 N 加默认值**,必须问用户。
  - `.claude/skills/marker-pixelize/data/palette-2.6mm-221.json` — 从 `30-Resources/marker-2.6mm-221colors.md` 抽出的 JSON,格式 `{code, hex, rgb}`。
  - `.claude/skills/marker-pixelize/scripts/pixelize.py` — 主脚本。流程:load palette → center-crop → LANCZOS resize N×N → 每像素 RGB 欧氏距离找最近色号 → 渲染大图(每格 cell 像素,细黑边,中央写色号,文字色按 YIQ 亮度自动黑/白)。
- **端到端验证**:512×512 测试图(HSV 渐变 + 红圆 + 蓝矩 + 黄星)→ N=32 → 2400×2400 输出。红圆映射到 F 系(F03/F04),蓝矩到 C 系(C07),黄星到 A 系(A05/A26),背景渐变过渡自然。43 种色号覆盖 1024 格。
- **设计取舍**:
  - **默认 cell 自动**:`2400 // N`,最小 12。避免用户手动算尺寸。
  - **cell < 16 不画色号**:超小格子挤不下字,直接跳过。
  - **RGB 欧氏距离**足够,没上感知色差(CIEDE2000)。221 色分布密集,肉眼看差别不大。
  - **裁成正方形是默认行为**,不加 --keep-aspect 选项 —— 用户明确要过了。
- **触发时机**:「格子图 / 像素化 / 用色卡涂色 / 按色号涂色 / 变成 N×N 像素」。harness 加载 skill 时通过描述自动匹配。
