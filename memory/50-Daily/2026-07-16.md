  1. **首私自动触发 / ChatGate / MediaTransfer 全部下沉到 Phase 2** —— v1 只做"回复现有消息",不做 CE→SEND_DM 自动首私;aichat 只保留最小接入(生成 reply 文案),不做 prompt 分平台。

  4. **新增 3 个 SC 专用 BehaviorType + 2 张表** —— `FETCH_STORY` / `LOGIN` / `SESSION_CHECK`;`sp_sc_device_session`(device × platform 登录状态) / `sp_sc_story_log`。
